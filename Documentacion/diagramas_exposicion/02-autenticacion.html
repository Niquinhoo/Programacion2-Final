El login separa entrada, verificación y navegación

La decisión visual traduce las guard clauses de `Login`, la ejecución asíncrona y la consulta del DAO. Hay tres resultados explícitos: campos incompletos, credenciales inválidas o `Menu` con el usuario autenticado.

public Usuario iniciarSesion(String usuario,
                             String contrasena) {
    if (usuario == null || usuario.isBlank()
            || contrasena == null || contrasena.isBlank()) {
        return null;
    }
    return usuarioDAO.autenticar(usuario.trim(), contrasena);
}

Qué decir

“La UI no decide si la credencial es válida”

La vista valida lo mínimo para dar una respuesta rápida; la autenticación real queda en `UsuarioService` y `UsuarioDAOImpl`. `AsyncDataLoader` evita bloquear la interfaz mientras la consulta accede a la base.
