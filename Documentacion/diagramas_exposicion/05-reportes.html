Data flow · reportes y visualización

Los datos agregados llegan a la pantalla como DTOs

El panel de reportes solicita tres lecturas, el servicio las delega al DAO y las vistas SQL condensan la información. La GUI recibe listas tipadas y recién allí construye líneas, barras y anillos con JFreeChart.

AsyncDataLoader.load(this,
    () -> {
        ResumenGeneralDTO resumen =
            ServicioFactory.getReporteService().resumenGeneral();
        List<VentaPorMesDTO> mensuales =
            ServicioFactory.getReporteService().ventasPorMes();
        List<VentaPorProductoDTO> productos =
            ServicioFactory.getReporteService().ventasPorProducto();
        return new Object[]{resumen, mensuales, productos};
    },
    data -> {
        cargarGraficoVentas((List<VentaPorMesDTO>) data[1]);
        cargarGraficoTorta((List<VentaPorProductoDTO>) data[2]);
    });

Qué decir

“Cada capa devuelve una forma de dato más útil”

La vista SQL hace la agregación, el DAO mapea filas a DTOs, el servicio conserva una API simple y la GUI transforma esos DTOs en datasets de JFreeChart. Así la pantalla no conoce tablas ni sentencias SQL.
